# Welcome to Peermeld Docs

**Peermeld** is the professional network for **developers, designers, founders and creators** to showcase real work, find collaborators and launch ideas. It is built around one belief: your work should speak louder than your job title.

<Callout type="info">
  These docs cover the live platform at [peermeld.com](https://peermeld.com). If you only read
  three pages, read [Quickstart](./quickstart), [The Feed](./feed) and [Claim your
  Subdomain](./getting-started/claim-subdomain).
</Callout>

## What is Peermeld?

Peermeld combines the best parts of a social feed, a portfolio host, a product launch board and a talent directory into one clean, fast network:

- **A Feed for builders** — [peermeld.com/feed](https://peermeld.com/feed) is where the community posts progress, ideas, questions, changelogs and launches, across the **Newest**, **Trending** and **Following** tabs.
- **A profile that ranks** — every member can claim `yourname.peermeld.com`, a fast, search-engine-ready personal page with your posts, portfolio and projects.
- **Proof of work** — project showcases with logos, screenshots, tech-stack tags and markdown build logs; portfolios with themes; a weekly **Launch** leaderboard.
- **Real reputation** — daily **streaks**, **Top Streaks This Week**, the **Peers Wallet** and a reward system turn consistent activity into visible reputation.

## Who Peermeld is for

Peermeld was born in the developer community, but it is open to **every profession that helps great work happen**:

| You are a…            | Peermeld helps you…                                              |
| --------------------- | ---------------------------------------------------------------- |
| Developer             | Ship build logs, show your stack, get discovered by teams        |
| Designer              | Publish visual case studies and portfolio blocks                 |
| Founder / Indie maker | Launch products on the weekly board and find co-builders         |
| Creator / Writer      | Curate knowledge on the Feed and grow an audience                |
| Student / Job seeker  | Turn learning-in-public into a profile recruiters actually read  |
| Recruiter / Team      | Search the directory by role, skills and real shipped work       |
